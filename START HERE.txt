GLOVE FOR WINDOWS

Run Glove-Setup-x64.exe to install Glove for your Windows account. Open Glove
from Start. If you use the portable build, keep the complete folder together
and open Glove.exe. This Windows x64 preview is unsigned.

TRANSFER FILES
In Personal > File sharing, choose Start file sharing. Scan the QR with your phone's
ordinary camera, then open the link in the phone browser. You can add files
from Windows or upload from the phone. Received files go to Downloads\Glove
unless you choose a different receive folder.

The browser session uses HTTP on your local network. Use trusted private Wi-Fi
and stop sharing when finished. Received files stay on your PC.

ANDROID NOTIFICATIONS
In Personal > Notifications, choose Share Android installer. Use the File
sharing QR to download Glove-Companion.apk to the phone and install it.
Choose Continue to pairing, then Pair Android. Scan the new QR from inside
Glove Companion, check the matching six-digit code, and approve on Windows.
Grant notification access in Android Settings and choose which apps can share.
Developer options are unnecessary for this connection.

Android may block notification access for a manually installed preview. If
the system offers Allow restricted settings in the trusted app's App info
menu, use that option before granting notification access. The preview inbox
shows recent active notifications from selected apps and supports replies when
the source notification offers one. Pause or forget the phone at any time.

DEVELOPER
Use Developer > Android screen for scrcpy and Wireless debugging. The Android
11+ setup guide covers Developer options, the Wireless debugging QR scanner,
and manual pairing. Use Developer > MCP for optional local Android testing.
The MCP client needs Node.js 24+. See MCP.md for setup.

IPHONE
Use File sharing from the iPhone browser. The separate screen-viewing preview
targets iOS 27+ and needs a compatible Safari screen picker. Follow Glove's
certificate verification steps before trusting the downloaded profile.
Physical iPhone screen playback still needs testing.
