Use Glove with MCP

Give a local coding assistant a view of your authorized Android test device over the same wireless connection Glove uses.

Connect your test device

  1. Pair the device in Glove using Android’s Wireless debugging settings and confirm it appears as connected.
  2. Install Node.js 24 or newer. In Glove, open Settings → Developer tools, select the connected device, and copy the configuration for Codex or Claude Code. Other stdio clients can use the server command from the repository guide.
  3. Open your client’s MCP tool list and choose the intended device before requesting a screenshot or running a UI check.

The repository guide includes the exact setup commands for Codex, Claude Code, VS Code and other stdio clients. Read the Glove MCP setup guide.

The Glove Mobile QA skill gives assistants a repeatable flow for selecting a device, capturing a screen and reporting the result. Open the Glove Mobile QA skill.

Tools and permissions

Discover devices
List Android devices already authorized in ADB.
Capture the screen
Request a screenshot from a selected test device.
Opt in to input
Enable the basic UI actions in the MCP guide when a test needs them. Keep inspection read only for screenshot tasks.

The server runs on the Windows PC over standard input and output. Phone pairing and authorization happen through Android and Glove. iPhone viewing uses the separate Glove screen viewer.

Screenshots can contain personal information. Use a test phone or a clean test screen and check your MCP client’s settings before sending an image to its model provider.
